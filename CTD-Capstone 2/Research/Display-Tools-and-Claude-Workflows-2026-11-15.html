Display tools, and how Claude can build in each one

We are choosing between p5.js, TouchDesigner, Unity and Blender for the digital world. This page compares them for MetamorphUs and answers a second question: in which of them can Claude make the actual files, animations and renders for us, and what would we have to install first?

Facts come from the linked sources, checked Nov 15, 2026. “Our read” marks judgment. Nothing here is a decision. Labels: Works today Needs setup Less likely

The short version

What we found

  • All four tools can be driven by Claude. p5.js needs nothing extra. Blender, TouchDesigner and Unity each have a connector (an “MCP server”) that lets Claude control the open app.
  • Only p5.js works today on Kaitlyn’s Mac. Blender, TouchDesigner, Unity, Node and uv are not installed on it (checked Nov 15). Claude already built our forest-to-butterfly animation this way.
  • Blender and TouchDesigner connectors are free and take about 15 minutes to set up. Both are community projects, not made by Blender or Derivative.
  • Unity has the most official support (a first-party Claude Code plugin since Sept 9, 2026), but it is the most setup and the least matched to our glowing, layered look.
  • Our read: Blender is for making assets, not for running the live installation. The live world would run in p5.js, TouchDesigner or Unity, with Blender feeding it models and renders.

Part 2

How Claude would work in each

For each tool: what the workflow looks like, what to install, and the limits.

p5.js

Works today
How it works
You describe what you want; Claude writes the sketch as files in our repo, opens it in a headless browser, takes screenshots and fixes what looks wrong. This is how our Nov 11 animation and Nov 13 hero shots were made.
Setup
None. To play it with the Arduino, open the page in Chrome or Edge.
Limits
Everything is code, so there is no visual editor for Austin to tweak by hand. Blender models can come in as OBJ or STL files. Our read: heavy 3D or tens of thousands of glowing particles may run slower than in TouchDesigner; a glow test would show this.
Optional extras
Two small community connectors exist (genart-mcp, p5js-ai-editor). Our read: we don’t need them, since Claude Code already edits and previews the files.

TouchDesigner

Needs setup
How it works
With TouchDesigner open, Claude adds and connects nodes, sets their parameters, runs Python inside the project, reads node errors, and pulls a node’s image to see the result. The most-listed connector has 14 tools.
Setup
  1. Install TouchDesigner (free non-commercial) and Node.js (version 22.18 or later, or 24).
  2. Download touchdesigner-mcp-td.zip from the project’s releases and drag mcp_webserver_base.tox into the project. Keep its folder intact.
  3. In a terminal: claude plugin marketplace add 8beeeaaat/touchdesigner-mcp then claude plugin install touchdesigner@touchdesigner-mcp
  4. Run /touchdesigner:setup in Claude Code to confirm the connection.
Limits
The app must be open while Claude works. The free version caps output at 1280 × 1280, which is below a 1080p-wide (1920) screen; full resolution needs the $300 Educational license. The connector can run any Python in the project, so save first. Other connectors exist (johnsabath, aliphi, a PyPI package); we have not compared them hands-on.
Arduino
Derivative’s guide covers Arduino through the Serial DAT. It warns that println() adds blank lines, and to switch the Serial DAT off while uploading a sketch.

Blender

Needs setup
How it works
With Blender open, Claude runs Python in the live scene, reads a summary of the objects, and looks at the viewport, the camera view or a strip of animation frames to check its work. It can also pull free Poly Haven textures, HDRIs and models with no account.
Setup
  1. Install Blender (3.0 or newer) and uv (brew install uv).
  2. In a terminal: claude mcp add blender uvx mcp-for-blender
  3. Then: uvx mcp-for-blender install-addon
  4. In Blender: Edit › Preferences › Add-ons, enable “MCP for Blender”. Press N in the 3D view, open the MCP tab, click Start MCP Server.
Limits
Our read: Claude is good at scene setup, materials, lighting, cameras, batch renders and exports, and at simple procedural shapes. It is not a replacement for Austin’s hand-modeled plants or butterfly. The add-on runs any Python in Blender with no password, so save first and keep it on this computer only. AI model generators (Hyper3D, Hunyuan3D, Tripo, Meshy) and Sketchfab need their own accounts or keys.
Without the connector
Our read: Blender can also run a Python script from the terminal with no window, so Claude could write a script and render stills that way once Blender is installed.

Unity

Less likely
How it works
Claude reads the scene hierarchy, creates and edits GameObjects and components, writes C# scripts, and reads the console to fix errors.
Option A: official
Unity released a first-party plugin for Claude Code on Sept 9, 2026. It installs Unity’s skills, the Unity CLI and Unity’s MCP server. Unity’s MCP needs Unity 6 or later, a project connected to Unity Cloud, and an active trial or subscription to Unity’s AI tools.
Option B: community
MCP for Unity by CoplayDev is free (MIT), works with Unity 2021.3 through 6.x, needs Python 3.10+ with uv, and can set up Claude Code from a window inside Unity. It is not affiliated with Unity.
Limits
Largest install and the steepest learning curve. Our read from Nov 13 still holds: Unity’s defaults lean toward a realistic 3D look, not our glowing, layered style. Whether Unity’s AI tools are included for students is unverified; its pricing pages disagree.

Part 4

What we could not confirm

  • Latest version numbers and release dates for the Blender and TouchDesigner connectors. Their pages did not show them.
  • The minimum TouchDesigner version for the connector. Its guide says only “latest version recommended.”
  • Whether the TouchDesigner 1280 × 1280 non-commercial cap is unchanged. It comes from our Nov 13 check of Derivative’s licensing page.
  • Whether Unity’s AI tools and official MCP are included with the free Student or Personal plans. One page lists a 14-day trial for Personal; others differ.
  • A third-party guide says Unity’s MCP server may be replaced by the Unity CLI. Unity’s own pages still describe it as current.
  • We have not installed or run any of the three connectors. Everything about them here is from their documentation.
